# Руководство пользователя Finam Terminal

**Finam Terminal** — это терминальное приложение для торговли на фондовом рынке через брокера Финам. Программа работает прямо в консоли и позволяет отслеживать портфель, просматривать котировки, анализировать графики и совершать торговые операции — всё без необходимости открывать браузер или тяжёлый торговый терминал.

## Возможности

- Просмотр портфеля и позиций по нескольким счетам
- История сделок за последние 30 дней
- Управление активными заявками
- Поиск инструментов с котировками в реальном времени
- Витрина бумаг Индекса МосБиржи с ценами в реальном времени и переходом к покупке
- Вкладка Analytics: структура портфеля по типам и секторам, маржа и риск, концентрация, результат по сделкам (FIFO), движение денег, итог с открытия счёта с XIRR и сравнением с IMOEX, ожидаемые выплаты, квоты Trade API
- Профиль инструмента со свечным графиком и календарями корпоративных действий (дивиденды и сплиты для акций, купоны/амортизация/оферты для облигаций)
- Создание заявок: рыночные, лимитные, стоп-лосс, тейк-профит, связанные SL+TP
- Автоматическое обновление данных: котировки активного счёта приходят потоком в реальном времени, с автоматическим возвратом к опросу раз в 5 секунд при обрыве связи
- Автообновление программы: проверка новых версий раз в сутки и установка обновления с перезапуском в один шаг
