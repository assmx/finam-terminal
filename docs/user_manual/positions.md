# Позиции

Вкладка «Позиции» — главный экран приложения. Здесь отображаются все открытые позиции на выбранном торговом счёте.

![](../../media/portfolio.png)

## Колонки таблицы

| Колонка | Описание |
|---------|----------|
| **Instrument** | Название инструмента (или тикер, если название недоступно) |
| **Qty (Lots)** | Количество в лотах. Положительное — длинная позиция (лонг), отрицательное — короткая (шорт) |
| **AvgPrice** | Средняя цена входа в позицию, в единицах котировки инструмента (у облигаций — процент от номинала) |
| **Current** | Текущая рыночная цена инструмента, в тех же единицах |
| **Daily P&L** | Дневной P&L — прибыль или убыток за текущий торговый день |
| **Value** | Стоимость позиции = текущая цена × количество; у облигации — количество × цена × номинал / 100. У заблокированной бумаги — жёлтое `BLOCKED` (см. ниже) |
| **Unreal P&L** | Нереализованный P&L — разница между текущей стоимостью и ценой входа |

### Валюта сумм

Суммы в колонках **Value**, **Daily P&L** и **Unreal P&L** — в валюте счёта, если рядом не стоит код другой валюты. У позиции в другой валюте код стоит прямо в ячейке: `2516.80 USD`, `+5.00 USD`. Так колонка не складывает доллары с рублями молча.

- **Value** — в валюте, в которой номинирована бумага: у акции — в валюте её котировки, у облигации — в валюте номинала. Замещающая облигация с номиналом в долларах показывается в долларах, хотя расчёты по ней идут в рублях.
- **Daily P&L** и **Unreal P&L** — в той валюте, в которой их прислал брокер. Обычно это валюта бумаги; если по цифрам видно, что брокер уже пересчитал результат в рубли, кода нет.
- Пока терминал уточняет валюту номинала облигации (номинал в одной валюте, расчёты в другой), **Value** показывает оценку одной бумаги от брокера в валюте расчётов. Это верная сумма, неизвестна только валюта; через несколько секунд, когда валюта номинала станет известна, стоимость переключится на номинал. Уточнение идёт, пока открыт «Обзор» вкладки [Analytics](analytics.md#панель-валюты).

Колонка **Value** и панели вкладки [Analytics](analytics.md) считаются одной и той же функцией, поэтому разойтись не могут.

### Заблокированные бумаги

Бумаги, заблокированные после санкций (фонды FinEx, иностранные акции с СПБ Биржи и подобные), остаются в списке позиций, но брокер оценивает их в ноль и не включает в эквити счёта. Поэтому в колонке **Value** у такой бумаги вместо суммы стоит жёлтое **`BLOCKED`**: сумма здесь была бы деньгами, которые нельзя получить.

- В колонке **Instrument** — название бумаги из списка брокера (например, `FinEx Russian RTS Equity MOEX` для `FXRL`; брокер обрезает такие названия до 30 символов).
- **AvgPrice**, **Current**, **Daily P&L** и **Unreal P&L** — как их прислал брокер; результат по заблокированной бумаге он обычно обнуляет.
- Котировки по ней не запрашиваются и в поток не попадают: запрос котировки такой бумаги зависает, а поток с ней замолкает целиком, вместе с ценами остальных позиций.

Что осталось за скобками оценки, показывает «Обзор» вкладки [Analytics](analytics.md#заблокированные-бумаги) — строкой `заблокировано: N · X RUB по цене брокера`.

## Обновление котировок

Котировки по выбранному счёту приходят потоком в реальном времени: колонка **Value** пересчитывается по мере сделок на бирже, а не раз в несколько секунд. Колонки **AvgPrice**, **Current**, **Daily P&L** и **Unreal P&L** приходят от брокера вместе с позициями и обновляются раз в 5 секунд.

- Подписка охватывает инструменты активного счёта и инструмент открытого [профиля](profile.md); при переключении счёта она автоматически переключается вместе с ним.
- Если поток обрывается (например, пропала сеть), приложение само возвращается к опросу цен раз в 5 секунд — данные продолжают обновляться, просто реже. Когда связь восстанавливается, поток подхватывается обратно.
- По остальным счетам цены всегда обновляются раз в 5 секунд.

Обновление данных вручную по-прежнему доступно по клавише **R**.

## Цветовая индикация

- **Зелёный** — положительное значение (прибыль)
- **Красный** — отрицательное значение (убыток)
- **Белый** — нулевое значение

Строки таблицы чередуются по цвету фона для удобства чтения.

## Действия

| Клавиша | Действие |
|---------|----------|
| ↑ / ↓ | Навигация по списку позиций |
| Enter | Открыть [профиль инструмента](profile.md) для выбранной позиции |
| A | Создать новую [заявку](trading.md#создание-заявки) по выбранному инструменту |
| C | [Закрыть позицию](trading.md#закрытие-позиции) — открывает окно с предзаполненными параметрами |
| ← / → | Переключиться на другую вкладку |
| S | Открыть [поиск инструментов](search.md) |
| R | Обновить данные |

## Пустой список

Если на счёте нет открытых позиций, таблица будет пустой. Используйте [поиск](search.md) (клавиша S), чтобы найти нужный инструмент и создать заявку.
