# Профиль инструмента

Профиль — это полноэкранное окно с подробной информацией об инструменте: характеристики бумаги, текущие котировки, торговые параметры, расписание сессий, календари корпоративных действий и свечной график.

![](../../media/instrument_profile.png)

## Как открыть

- **Enter** на выбранной позиции во вкладке «Позиции»
- **P** на выбранном инструменте в окне [поиска](search.md)
- **Enter** во вкладке «Индекс» или «Commodities»

Профиль из **Commodities** показывает международную котировку и свечной график. Имя берётся из поля `name`, без подписи единицы цены. Торговые параметры, расписание и календари этой информационной серии не загружаются. Если по `moex_mask` найден действующий контракт с известной экспирацией, `A`/`Ф` открывают заявку **по этому контракту MOEX**, указанному в подсказке. Контракт автоматически меняется за `roll_days` до экспирации; уже открытая заявка по старой серии отклоняется, а не переносится молча. Без подходящей связи заявка недоступна. `1–4`, `R` и `Esc` работают как обычно.

## Левая панель — информация

### Детали инструмента

| Поле | Описание |
|------|----------|
| **Type** | Тип инструмента (акция, облигация, фьючерс и др.) |
| **Board** | Торговая площадка / режим торгов |
| **ISIN** | Международный идентификационный код |
| **Currency** | Валюта котирования и расчётов. У облигации это не обязательно валюта номинала — см. `Face Value` ниже |
| **Lot Size** | Размер лота (количество бумаг в одном лоте) |
| **Decimals** | Количество знаков после запятой в цене |
| **Min Step** | Минимальный шаг цены |
| **Expiry** | Дата экспирации (для фьючерсов и опционов) |

### Специфичные поля по типу инструмента

Под общими деталями показывается блок, зависящий от типа бумаги:

| Секция | Поля |
|--------|------|
| **Futures** (фьючерс) | `Contract` — размер контракта |
| **Options** (опцион) | `Contract` — размер контракта, `Strike` — цена исполнения |
| **Bond** (облигация) | `Face Value` — номинал и его валюта |

Для акций такой блок не отображается.

> **Валюта номинала.** API называет валюту номинала только в календаре выплат облигации, поэтому профиль берёт её из этого календаря — того же, что показывает секции `Coupons`, `Amortization` и `Offers`. Отдельного запроса ради неё профиль не делает. Если календарь не загрузился или не называет валюту, номинал показывается **без валюты**: подставить валюту из строки `Currency` было бы ошибкой, потому что это валюта расчётов. Например, замещающая облигация «РФ ЗО 27 Д» торгуется в рублях, а её номинал — 200 000 долларов: профиль покажет `Currency RUB` и `Face Value 200000.0 USD`, а без календаря — `Face Value 200000.0`. Клавиша **R** загружает календарь заново. Если валюту номинала этой облигации уже узнала вкладка [Analytics](analytics.md), профиль покажет её, даже когда его собственный календарь не загрузился.

### Календари корпоративных действий

Для акций и облигаций профиль показывает компактные календари корпоративных действий. В каждой секции отображается до **3 прошлых** и **3 будущих** событий, отсортированных по дате; если событий больше, добавляется подсказка `…`. Секция не отображается, если по инструменту нет соответствующих событий.

**Для акций:**

| Секция | Содержимое |
|--------|-----------|
| **Dividends** | Дата закрытия реестра, размер дивиденда на акцию и валюта |
| **Splits** | Дата, коэффициент конвертации (`старое→новое`) и новый размер лота |

**Для облигаций:**

| Секция | Содержимое |
|--------|-----------|
| **Coupons** | Дата выплаты, ставка купона в процентах и дата фиксации реестра |
| **Amortization** | Дата, доля погашения в процентах и новый номинал |
| **Offers** | Окно дат предъявления, тип оферты (PUT / CALL) и цена |

Для фьючерсов и опционов календари не запрашиваются и не отображаются.

### Котировки

| Поле | Описание |
|------|----------|
| **Last** | Цена последней сделки |
| **Bid** | Лучшая цена покупки (с указанием объёма) |
| **Ask** | Лучшая цена продажи (с указанием объёма) |
| **Volume** | Объём торгов за сессию |
| **Open** | Цена открытия |
| **High** | Максимальная цена за сессию |
| **Low** | Минимальная цена за сессию |
| **Close** | Цена закрытия предыдущей сессии |
| **Open Int.** | Открытый интерес — показывается для фьючерсов и опционов, когда значение ненулевое |

Пока профиль открыт, котировки обновляются в реальном времени по потоку данных биржи — см. [Позиции → Обновление котировок](positions.md#обновление-котировок). График свечей обновляется отдельно, раз в 5 секунд.

### Торговые параметры

| Поле | Описание |
|------|----------|
| **Tradable** | Доступен ли инструмент для торговли (Yes / No) |
| **Longable** | Можно ли открывать длинные позиции |
| **Shortable** | Можно ли открывать короткие позиции |
| **Trade Lot** | Торговый лот — количество бумаг в одном лоте при выставлении заявки. Показывается, только если брокер сообщает это значение |
| **Risk rates** | Риск-ставки для лонга и шорта |
| **Margin** | Начальная маржа для лонга и шорта |

> **Lot Size и Trade Lot.** `Lot Size` в деталях инструмента — справочный размер лота бумаги, а `Trade Lot` — тот лот, по которому брокер считает объём заявки. Обычно они совпадают; если значения различаются, приложение использует `Trade Lot` — и в подписи к полю количества в [окне заявки](trading.md#создание-заявки), и при отправке заявки. Когда брокер не сообщает торговый лот, строка `Trade Lot` не отображается и используется `Lot Size`.

### Расписание торговых сессий

Список торговых сессий с указанием времени начала и окончания. Типы сессий: основная, утренняя, вечерняя, аукцион открытия, аукцион закрытия и другие.

## Правая панель — свечной график

График отображает ценовую динамику инструмента в виде японских свечей:

- **Зелёные свечи** — рост (цена закрытия выше цены открытия)
- **Красные свечи** — падение (цена закрытия ниже цены открытия)
- **Тело свечи** — диапазон между ценами открытия и закрытия
- **Тени (фитили)** — максимум и минимум за период

По оси Y отображается цена, по оси X — время.

### Таймфреймы

Переключение между таймфреймами — клавишами **1–4**:

| Клавиша | Таймфрейм | Период данных | Формат времени на оси X |
|---------|-----------|---------------|------------------------|
| **1** | M5 (5 минут) | 7 дней | ЧЧ:ММ |
| **2** | H1 (1 час) | 30 дней | ЧЧ:ММ |
| **3** | D (день) | 1 год | ДД.ММ |
| **4** | W (неделя) | 5 лет | ДД.ММ.ГГ |

## Действия

| Клавиша | Действие |
|---------|----------|
| 1–4 | Переключить таймфрейм графика |
| A | Создать [заявку](trading.md#создание-заявки) по этому инструменту |
| R | Обновить данные профиля и график |
| S | Открыть [поиск инструментов](search.md) |
| Esc | Закрыть профиль и вернуться к основному экрану |
