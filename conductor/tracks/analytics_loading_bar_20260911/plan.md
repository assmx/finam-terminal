# Plan: Analytics — полоса прогресса загрузки истории на «Сделках» и «Деньгах»

## Overview
Сейчас во время прохода по истории на «Сделках» и «Деньгах» видны текстовая строка «История: запрос N из ~M…» и пустые рамки «История ещё не загружена». Их заменит одна полоса прогресса: жёлтая заливка на фоне цвета статусной строки, процент по центру, во всю ширину и в средней строке области. Прогресс считается в реальных шагах: завершённые окна истории плюс два окна баров IMOEX. Новых запросов нет. Разработка по TDD.

  - Acceptance: юнит- и интеграционные тесты зелёные
  - Note: тест «окна == оценка» нашёл два расхождения, из-за которых завершённый проход не дошёл бы до 100%.
