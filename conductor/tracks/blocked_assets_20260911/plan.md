# Plan: Заблокированные активы — распознавание, оценка вне базы, защита от зависающих запросов

## Overview
Учим терминал узнавать заблокированную бумагу по данным, которые у него уже есть: по площадке `_SPBZ`/`_MMBZ` и по двойнику из массового списка у позиции без MIC. Такая бумага не входит в оценку портфеля: на «Обзоре» она показана отдельной строкой, в колонке Value — меткой `BLOCKED`. Ни `LastQuote`, ни `GetAssetParams`, ни `SubscribeQuote` по ней не уходят, потому что эти вызовы зависают, а подписку заблокированный символ глушит целиком. Разведка — в spec.md. Разработка по TDD.
